# Seclusa Games

A handful of small games in one app you can add to your phone or computer.

They all run in your browser. No sign-up, no adverts, and nothing about how you
play is ever sent to anyone.

## Forked From

Some of these games began as other people's work:

- **Klondike and Pyramid** come from
  [Simple Solitaire Collection](https://github.com/TobiasBielefeld/Simple-Solitaire)
  by Tobias Bielefeld, by way of
  [Seclusa Solitaire](https://github.com/ambr3/Seclusa-Solitaire).
- **Seclusa Munch** is based on
  [pacman](https://github.com/masonicGIT/pacman) by masonicGIT. The maze and the
  rules come from
  [Jamey Pittman's Pac-Man Dossier](https://home.comcast.net/~jpittman2/pacman/pacmandossier.html),
  which worked out how the original arcade game actually behaved. An earlier
  browser version is by Shaun Williams.
- **Seclusa Blocks** and **Word Puzzle** are my own.

The full licence text is in [LICENSE](LICENSE). Seclusa Munch also keeps a
copy as [games/pacman/COPYING](games/pacman/COPYING). Each game names what it
is built on inside the game itself, under About.

## Features

- Version 0.1.29
- The games: Seclusa Blocks, Seclusa Klondike, Seclusa Munch, Seclusa Pyramid,
  Word Puzzle
- Sound, how-to-play, theme and about buttons across the top
- Your scores and settings are remembered on your device
- Add it to your home screen and it opens on its own, no browser needed, and
  works with no internet connection

GitHub Pages cannot send custom security headers, so [MDN HTTP Observatory](https://developer.mozilla.org/en-US/observatory) rates this site **B** ([report](Scan%20results%20-%20HTTP%20Observatory%20_%20MDN.pdf)).
For a static same-origin PWA with a tight page CSP that is expected and fine — the missing headers are a host limit, not a gap in how the app itself behaves.

## Usage

Open it and pick a game.

To add it to your home screen, open your browser's menu and choose "Add to Home
Screen".
